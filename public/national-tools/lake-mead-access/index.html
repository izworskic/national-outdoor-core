The decision

What this tool is trying to answer

Lake Mead access changes by ramp and vessel type. The launch workbench reads the named NPS ramp table instead of inferring access from lake elevation alone, and it surfaces any conflict between a current NPS OPEN status and a numeric threshold rather than silently overruling the official status.

  • Motorized and non-motorized access can differ at the same launch site.
  • Current NPS OPEN or CLOSED status controls; a numeric elevation threshold is supporting context, not permission to invent a different status.
  • Construction, portable mats, trailer limits and local conditions can change practical access independently of lake level.

How to use this result

Make the decision from the status, freshness and evidence together

Start with the current decision and the trip consequence above it, then check the timestamp and source excerpt. A favorable condition is not a blanket all-clear. If the tool returns VERIFY or LIVE SOURCE UNAVAILABLE, open the official source instead of treating an old reading as current. Recheck close to departure because roads, alerts, water levels and mountain weather can change after you first plan the trip.
