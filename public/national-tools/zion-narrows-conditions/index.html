The decision

What this tool is trying to answer

The Narrows is a conditions problem, not a generic hiking forecast. River flow changes difficulty, NPS uses specific flow thresholds for closures and permits, and flash-flood warnings can override an otherwise modest gauge reading. This tool puts those pieces in one place.

  • Bottom-up Narrows access closes when flow is above 150 cfs.
  • Top-down Narrows access above Big Spring closes when flow is above 120 cfs.
  • An active Flash Flood Warning closes The Narrows; NPS keeps it closed for at least two hours after the warning is lifted.

How to use this result

Make the decision from the status, freshness and evidence together

Start with the current decision and the trip consequence above it, then check the timestamp and source excerpt. A favorable condition is not a blanket all-clear. If the tool returns VERIFY or LIVE SOURCE UNAVAILABLE, open the official source instead of treating an old reading as current. Recheck close to departure because roads, alerts, water levels and mountain weather can change after you first plan the trip.
